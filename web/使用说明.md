# 显影 · 使用说明（人话版）

> 给「不想先读十页文档、只想把图生出来」的人。
> 详细的参数与实现见 `README.md`，版本变化见 `CHANGELOG.md`。

---

## 1. 它是干嘛的

一个本地生图 / 改图的壳：你在它的界面里写提示词、调参数、看图；
它自己在后台把 ComfyUI 拉起来，**不弹 ComfyUI 那个满屏节点的界面**。

- 关了显影，ComfyUI 默认也跟着关（设置里能改）
- 第一次用要先在「设置」里指一下 ComfyUI 的目录，模型从 ComfyUI 的 `models` 目录读
- 全程本地，不出网（除非你自己接了在线 API 工作流）

## 2. 一分钟出第一张图

1. 双击显影，等左下角状态点变**绿**（或顶栏端口显示正常）
2. 左边「模型」下拉选一个（默认 MOSS-Image 就行）
3. 在「提示词」框里写你要的画面，中文也可以：
   `雨夜街头，一个女孩撑着透明雨伞，霓虹倒影，电影感`
4. 尺寸 / 步数 / CFG 先不用动，点最下面 **生成**
5. 右边图区出图，点图片可看大图、翻上下张、存参考图

> 第一次生成会慢一点（要加载模型）；后面同模型就快了。

## 3. 界面就三块

| 位置 | 是什么 |
|---|---|
| 左边一列 | 参数：模型、尺寸、步数、CFG、种子、LoRA、SLG… |
| 右边大片 | 图区：生成结果、图库、大图预览 |
| 顶上两条 | 顶栏（显影 / 状态 / 专业 / 图库 / 启动停止 / 设置）；项目栏（项目、镜头、版本、提示词、清空历史…） |

**简单 / 专业**：右上角「专业」按钮切换。简单模式藏掉大部分参数，只留模型、提示词、尺寸和生成。

## 4. 提示词这一块（重点）

提示词框下面只有一行状态，真正的工具在 **🧰 提示词辅助** 里，一共八格：

1. **姿势库** — 白模姿势图，点一条抄它的英文描述，或者直接加进参考图
2. **去 AI 感** — 一键补「自然光 / 中性白平衡 / 浅景深 / 噪点 / 轻微畸变」，专治塑料感；反向词会一起补
3. **扩写** — 一句话 → 完整画面描述（官方增强器；被拒时自动换本地模型）
4. **解析图** — 丢一张图，让本地视觉模型拆成分类提示词（可带 OCR 原文）
5. **排版** — MOSS 专用：画布上拖框，定文字和物体的位置（见第 6 节）
6. **助手** — 中文需求 → 翻译 → 扩写 → 提示词，走本地小模型
7. **提示词体检** — 生成前扫一遍毛病（见下）
8. **排版草稿** — 让本地模型按当前画布写一份 MOSS 排版 JSON，再进画布微调

### 风格（外套）
点「风格」选一个风格包，比如「电影感」。生成那一刻它会把固定那串词套在你的提示词外面，
还会把「不要的东西」加到反向提示词。**它不改你框里的字**，随时能换、能取消。

点「样式目录」可以打开文件夹自己加：
- `styles\*.json` = 风格包（`{name, positive, negative}`，`{prompt}` 是你的词）
- `styles\wildcards\*.txt` = 通配符词库，一行一个；提示词里写 `__lighting__` 会随机抽一条
- 种子固定时，同一处通配符每次都抽同一条（可复现）

风格面板里能搜、能收藏（☆）、能删（🗑，只删那一格）。

### 通配符 / 数组 / 内联 LoRA
- `__名字__` → 从 `wildcards\名字.txt` 里抽
- `[[甲,乙]]` → 每个候选各出一张（最多 8 组）
- `<lora:名字:0.8>` → 自动填进 LoRA 槽，并从提示词里删掉（不在模型列表里的会跳过）

### 提示词体检
只提示、不拦。会告诉你：通配符找不到文件、LoRA 不在列表、质量词堆一堆（`masterpiece, 8k` 这种 MOSS 不吃）、
太长（超过 4K token）、反向词是空的。

## 5. 图区 / 图库 / 项目

- **图区**右上角可以切「全部 / 本项目」；「大小」滑条控制缩略图
- **图库**按项目分：`output\projects\<项目>\` 里的图归那个项目；切换项目图库跟着换
- **项目栏**能新建 / 重命名 / 隐藏 / 删除，还有「回收站」「锁定区」
  - 隐藏 = 只是界面不显示
  - 锁定区 = 真加密（口令进去，10 分钟自动锁）
- 私密项目**不写提示词历史、不记版本**，生成走「先落临时、加密、再删明文」

## 6. 排版（MOSS 专用）

一句话：**拖框告诉模型「字放哪、东西放哪」**。

1. 🧰 → 排版，或者直接开画布
2. 加「文字」或「物体」框，拖到位置、写描述；文字框还要写**要渲染的原字**
3. 「按排版生成」→ 它会按 MOSS 官方格式（`abs_centralized` / `yxyx`）编译成提示词
4. 可以存模板、存排版版本；也能导入现成的排版 JSON

**两条硬规矩**（按官方规范校验，不合格不给生成）：
- 画布宽高必须是 **16 的倍数**
- 文字框必须写原字；框不能超出画布

不想手拖就用 **🧰 → 排版草稿**：本机模型按你的描述写一份排版 JSON，校验不过会自己重试，通过后直接进画布。

## 7. 镜头（画连续分镜）

「一话 = 一组镜头」。点顶部 **镜头**：

1. 面板顶部「✂️ 从一段剧情拆镜头」→ 贴剧情 → 设最多几格 → **拆分**
2. 拆出来的分镜一行一格，可以手动改
3. **存为镜头**（进镜头列表）或 **推送到队列**（批量出图）
4. 每一格可以：填入（把参数填回左边）/ 重画（换种子再生成）/ 删
5. 底部「整话导出」→ 选文件夹，输出每格最新图 + `story.md`

**单张图也能存成镜头**：点开任意一张图 → 大图底部 **存为镜头** → 选一格放进去，或「新建一格」。

## 8. 批量队列

左边「批量队列」折叠区：一行一条提示词 → 加入队列 → 开始。
可以暂停 / 继续 / 重排 / 单条移除 / 取消当前，会显示剩余条数和大概时间。
失败的条目进「问题」面板（顶栏消息里也能看到）。

## 9. 其他几个入口

- **版本**：每次生成自动记账，能 1–5 星、按时间/星排序、看父版本差异、从旧版分叉继续
- **超分**：右侧图片详情里放大；**局部重绘**：涂一块再重画
- **训练**：内置 kohya，训练前记得勾「重启清显存」；训练时必须由显影托管 ComfyUI
- **模型管理**：顶栏「模型」——扫 ComfyUI/models/**（78 个、9 类），显示大小/日期/底模/触发词，有 <模型>.preview.png 就显示预览；「禁用」只写一个 `.disabled` 标记，壳里的 LoRA 下拉会跳过它。
- **参数网格**：左侧「参数网格」里选两样（模型、尺寸、种子、CFG、步数、LoRA 强度、风格…），各填几个值，跑完拼成一张表；点一格采用那组参数。横扫的老用法留成「模型 × 尺寸」「预设 × 尺寸」两个模板按钮。
- **配方库**：把「模型 + LoRA + 参数 + 风格 + 排版 + 提示词」存成一份配方（全局或只当前项目），在 🧰 → 配方库 里一键应用；版本列表里也能「存为配方」。
- **自定义工作流**：导入 ComfyUI API 格式 JSON 后，生成页会多出「工作流参数」——自动从节点里找出步数、CFG、种子、采样器等可调项，改完只影响这个工作流；也可以在 JSON 里直接写 `{{prompt}} {{steps}}` 这类占位符。
- **备份 / 导出 / 导入**：设置里；导出私密项目要先解锁

## 10. 常见问题

**点了生成没反应？**
看左下角状态点：灰色=ComfyUI 没起来（点「启动」），黄色=正在启动。
状态点悬停能看到完整那句话。

**报「显存不足」？**
关掉别的占显存的程序；设置里勾「重启清显存」；或者把尺寸/步数调小。

**生成很慢？**
第一次是加载模型；MOSS 50 步本来就慢。想快：步数降到 30 左右，或换蒸馏模型。

**图存哪了？**
`ComfyUI\output\` 下面，按项目分子目录。图区右键/大图里都有「在文件夹中显示」。

**提示词里的中文模型能懂吗？**
MOSS / Qwen 能懂中文，但**画面里的文字**（招牌、标题）要在提示词里用引号原样写清楚，
比如：`招牌上写着"老街早餐"`。

**改了代码不生效？**
前端资源是打包进 exe 的，改了 `web\*.js` 要重新构建（`cargo tauri build --no-bundle`），光重启没用。
